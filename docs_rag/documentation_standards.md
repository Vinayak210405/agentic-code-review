# Institutional Documentation Standards

- DOC-01: Every public module, class and function has a Google-style docstring with a one-line summary, `Args:`, `Returns:` and `Raises:` sections where applicable.
- DOC-02: Docstrings describe behaviour and constraints, not implementation details.
- DOC-03: Each pull request includes a summary of changed modules, new public APIs and any security-relevant changes for the changelog.
- DOC-04: New HTTP endpoints must document method, path, authentication requirement, request schema and error responses.
